Panduan Lengkap Admin CMS

Selamat datang di dasbor pengelola konten portofolio. Panduan ini memandu Anda memperbarui setiap bagian website tanpa perlu coding sama sekali.

1. Profil & Bio

  1. Buka tab Profil & Bio di menu kiri.
  2. Klik tombol Choose File untuk mengunggah foto profil baru dari komputer Anda.
  3. Isi semua kolom: Nama, Jabatan, Institusi, Email, dan Tagline.
  4. Perbarui angka statistik (Publikasi, Sitasi, Tahun Mengajar, Negara Kolaborasi).
  5. Klik tombol Simpan Info Profil & Stats → akan muncul konfirmasi ringkasan perubahan.
  6. Klik Ya, Simpan untuk mengonfirmasi → website otomatis diperbarui.
💡 Tips: Foto profil disarankan berformat PNG transparan tanpa latar belakang untuk tampilan hero yang lebih profesional.

2. Menambah / Mengedit Publikasi

  1. Buka tab Publikasi di menu kiri.
  2. Isi semua kolom: Tahun, Kategori, Nama Jurnal, Judul Paper, dan URL tautan.
  3. Klik Simpan Publikasi ke CMS → konfirmasi akan muncul.
  4. Untuk mengedit: klik tombol Edit pada baris publikasi yang ingin diubah.
  5. Untuk menghapus: klik tombol Hapus → konfirmasi penghapusan akan muncul.
⚠️ Setiap penghapusan memerlukan konfirmasi. Tindakan ini tidak dapat dibatalkan.

3. Fokus Riset & Upload Gambar

  1. Buka tab Fokus Riset.
  2. Pilih kartu riset yang ingin diperbarui (Riset 1, 2, 3, atau 4).
  3. Klik Choose File untuk mengunggah gambar sampul riset.
  4. Isi Judul dan Deskripsi singkat penelitian.
  5. Klik Simpan → konfirmasi perubahan akan muncul.
💡 Gunakan gambar beraspek rasio 4:3 atau 16:9 (contoh: 800×600px) agar tampil proporsional di kartu riset.

4. Blog Artikel

  1. Buka tab Blog Artikel.
  2. Isi semua kolom: Judul, Kategori, Tanggal, Estimasi Waktu Baca, Ringkasan, dan Isi artikel.
  3. Klik Simpan Artikel → konfirmasi akan muncul sebelum disimpan.
  4. Edit atau hapus artikel yang sudah ada menggunakan tombol di daftar bawah.

5. Galeri Foto Kegiatan

  1. Buka tab Galeri.
  2. Klik Choose File untuk memilih foto dari komputer.
  3. Isi Judul dan Keterangan (caption) foto.
  4. Klik Simpan Item Galeri.
  5. Hapus foto lama yang tidak diperlukan dengan tombol Hapus.

6. Video Showcase

  1. Buka tab Video Showcase.
  2. Isi URL video YouTube dalam format embed: https://www.youtube.com/embed/VIDEO_ID
  3. Ganti VIDEO_ID dengan ID video YouTube Anda (angka/huruf setelah v= di URL normal).
  4. Upload foto banner/thumbnail video.
  5. Klik Simpan Pengaturan Video.
📹 Cara mendapat URL embed: buka video di YouTube → klik Bagikan → Sematkan (Embed) → salin URL dari src="...".

7. Simpan Permanen & Backup Data

  1. Buka tab Simpan & Export.
  2. Klik Simpan Perubahan Langsung untuk sinkronisasi instan ke browser.
  3. Klik Download content.json Terbaru untuk unduh file data lengkap.
  4. Unggah file content.json tersebut ke folder data/ di server/GitHub untuk deployment permanen.
  5. Klik Copy JSON ke Clipboard untuk salin data dan simpan manual.
⚠️ Data perubahan tersimpan di browser lokal (LocalStorage). Jika browser dibersihkan, data akan hilang. Selalu download & backup file content.json setelah setiap sesi update.

🔒 Keamanan & Konfirmasi Perubahan

  • Setiap aksi simpan akan menampilkan ringkasan perubahan yang akan diterapkan.
  • Setiap aksi hapus menampilkan peringatan merah dengan detail item yang akan dihapus.
  • Klik Batal untuk membatalkan dan kembali mengedit.
  • Klik Ya, Simpan / Ya, Hapus untuk mengonfirmasi tindakan.
  • Tombol Reset Data Awal akan mengembalikan semua data ke kondisi awal — pastikan Anda sudah backup sebelumnya.
